## 1. Условие варианта

Дан одномерный массив целых чисел размера `n`. Требуется найти `k`-й по
величине (то есть `k`-й минимальный) элемент массива.

Пример из методички: для массива `{4, 2, 7, 1, 9, 3}` при `k = 3`
ответ равен `3` (отсортированный массив `{1, 2, 3, 4, 7, 9}`, третий
элемент — `3`).

Кроме алгоритма варианта, программа реализует базовый набор операций над
динамическим массивом: создание, печать, вставку, удаление, изменение
размера.

## 4. API (include/lab01/array_ops.hpp)

```cpp
int* array_create(std::size_t size);        // new int[size](), память обнуляется
void array_delete(int*& arr);               // delete[] + обнуление указателя
int* array_resize(int* arr, std::size_t size, std::size_t new_size);
int* array_insert(int* arr, std::size_t& size, std::size_t pos, int value);
int* array_remove(int* arr, std::size_t& size, std::size_t pos);
void array_print(const int* arr, std::size_t size);
bool array_binary_search(const int* arr, std::size_t size, int target,
                         std::size_t& out_index);
int  array_kth_smallest(int* arr, size_t size, size_t k);
```

### Поведение функций

- **`array_create`** — выделяет массив через `new int[size]()` (значения
  обнуляются). При нехватке памяти `new` сам бросает исключение.
- **`array_resize`** — выделяет новую память, копирует
  `min(size, new_size)` элементов, освобождает старую. Если
  `new_size == size` возвращает исходный указатель без изменений; при
  `new_size == 0` освобождает память и возвращает `nullptr`.
- **`array_insert`** — вставка возможна при `pos <= size` (вставка в конец
  разрешена). При `pos > size` массив не изменяется. Размер увеличивается
  на 1.
- **`array_remove`** — удаление при `pos < size`. Если после удаления
  элементов не остаётся, память освобождается и возвращается `nullptr`.
- **`array_binary_search`** — классический бинарный поиск по
  **отсортированному** массиву, возвращает `true` и индекс через
  `out_index`.
- **`array_kth_smallest`** — делает копию массива, сортирует её
  быстрой сортировкой (`quick_sort`, Хоар) и возвращает элемент с индексом
  `k - 1`. Исходный массив не изменяется. При некорректных данных
  (`arr == nullptr`, пустой массив, `k == 0` или `k > size`) возвращает `0`.

### Алгоритм варианта

```
k-й по величине:
  sorted = копия массива
  quick_sort(sorted)               // средняя сложность O(n log n)
  ответ = sorted[k - 1]
```

Сложность: **O(n log n)** в среднем, **O(n²)** в худшем случае (выбор
опорного элемента по центру). Дополнительная память — **O(n)** (копия
массива).

## 5. Сборка

### Требования

- Компилятор **GNU GCC/G++** (проект намеренно запрещает другие
  компиляторы, см. `CMakeLists.txt`).
- CMake 3.20 или новее.
- Менеджер сборки: `mingw32-make` (MinGW) или `make`.
- GoogleTest подтягивается автоматически через `FetchContent`, если не
  найден в системе (нужен доступ в интернет при первой сборке).

### Команды

```bash
# Конфигурация (из корня проекта)
cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_CXX_COMPILER=g++

# Сборка
cmake --build build

# Запуск тестов
ctest --test-dir build --output-on-failure
```

После сборки появятся:

- `build/lab01_main.exe` — основная программа;
- `build/tests.exe` — модульные тесты.

### Флаги компиляции

- `-Wall -Wextra -Wpedantic -g` — строгие предупреждения и отладочная
  информация.
- **AddressSanitizer** (`-fsanitize=address`) включается автоматически,
  если поддерживается тулчейном. В MinGW-сборках `libasan` часто
  отсутствует — тогда CMake выводит предупреждение и собирает без него.

## 7. Тесты

Покрытие реализованных функций (`tests/array_ops_test.cpp`):

| Группа            | Что проверяется                                                        |
|-------------------|------------------------------------------------------------------------|
| `ArrayCreate`     | Выделение памяти и обнуление элементов                                 |
| `ArrayDelete`     | Обнуление указателя после освобождения                                 |
| `ArrayResize`     | Увеличение, уменьшение, тот же размер, уменьшение до нуля              |
| `ArrayInsert`     | Вставка в начало, середину, конец; некорректная позиция               |
| `ArrayRemove`     | Удаление из середины, последнего элемента; некорректная позиция       |
| `KthSmallest`     | Пример из методички, первый/последний элемент, один элемент, `k = 0`, `k > size`, пустой массив, неизменность исходного массива |

Запуск только тестов:

```bash
./build/tests.exe
```
